# ADR-013: Portaal, nog niet

- Status: voorgesteld
- Datum: 2026-11-16
- Besluitvormers: Dennis (eigenaar). Nog geen keuze.

## Context

`catalog-info.yaml` is al Backstage-vorm. Een portaal (Backstage of iets vergelijkbaars) is pas zinvol als beide waar zijn:

1. Meerdere teams willen ownership, documentatie en scorecards in één UI naast de graaf.
2. Er is een team dat dat portaal kan onderhouden.

## Besluit

Geen portaal in deze fase. De statische site en `catalog-info.yaml` houden de route open. Een portaal wordt een laag erboven, niet een tweede model.

## Gevolgen

- De scorecard (F4-8) blijft in de CLI, de site en MCP tot een team het portaal wil dragen.
- Uitrol voorbij de pilot wacht op expliciete goedkeuring van Dennis.
